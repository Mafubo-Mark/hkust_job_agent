# Session and RAG fixes — 23 September 2026

The program now accepts at most **30 dialogue rounds** per launch. `workflows/dialogue_graph.py` counts user turns, gives the 30th question its answer, and ends the session. LangGraph uses an in-memory checkpointer, so follow-up references work while the process runs but no conversation database is written.

The new `tools/bye_tool.py` recognizes goodbye, bye, “that's all, thanks,” `/exit`, and similar short endings. The actual `bye_tool` clears known generated outputs and ends the graph: resume text, the three job JSON files, the readiness marker, any partial-score checkpoint or error file, the vector database, and old conversation SQLite files and sidecars. `main.py` also cleans before every new preparation and when the process exits. This keeps the input `data/resume.pdf`, code, `.env`, the Python environment, and cached embedding/driver dependencies. A forced `kill -9` cannot execute Python cleanup; the next launch clears leftovers.

The no-rescan shortcuts (`--thread`, `--score-saved`, `--resume-scoring`, `--reindex`, `--prepare-only`) were removed from `main.py`. Each launch re-extracts the PDF, opens Chrome for an HKUST scrape, computes new scores, and rebuilds the RAG index. The original two-line score prompt remains the default. The internal reusable matcher still exposes its older modes, but the agent entry point always requests a full run and ignores prior results.

The `ValueError` in “find required jobs” came from requiring DeepSeek to classify every job and reproduce an exact source quote. A paraphrase or spacing change made the entire request fail. The tool now retrieves all saved job IDs from the full-description vector collection and, for explicit skills such as Python, checks saved requirements and descriptions directly. It returns company, title, Ref No., and a short source excerpt. All indexed jobs are considered, even beyond the top semantic hits. A skill mention is labelled as a mention because some listings say “preferred” or allow several languages. For other criteria, invalid model evidence is reported as uncertain and does not fail the entire search.

Verification used the actual LangGraph graph, in-memory checkpointer, SQLite vector store, and synthetic job fixtures. **49 automated checks passed**, covering 30 rounds, goodbye routing, output cleanup with PDF preservation, fresh preparation on two launches, and a full dialogue Python query across more jobs than a top-eight retrieval. A read-only copy of the existing 44-job dataset was also searched through its real vector index: the tool inspected **44 jobs** and returned **17 company/title matches** without a DeepSeek classification request or `ValueError`. The distinction between mandatory, optional, and alternative Python requirements still depends on reading each quoted listing. No live HKUST scrape or paid scoring call was made for this change.
